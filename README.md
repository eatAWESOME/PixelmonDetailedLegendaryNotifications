# PixelmonSpawnAlerts

Improved spawning alerts for Pixelmon.

Disabling `display-legendary-global-message` and `do-legendary-raid-event` in the pixelmon spawning config is recommended to prevent double notifications.

Alerts all players for legendary, mythical, and ultra beast spawns and raids. Also allows for players to set up alerts for when specific pokemon spawn near them using /spawnalert.
